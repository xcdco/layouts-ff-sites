// 01 — operations

Команды боевого расчёта.

/usr/local/bin/ff-*
01

Приёмка и сверка

ff intake --batch=<id> --photo=on

Поштучная фотофиксация на конвейере, сверка с УПД, расхождения — webhook в ЛК и Telegram.

photoupdwebhook
02

Маркировка

ff mark wb oz --kiz --honest

КИЗ, «Честный знак», термоэтикетки WB и OZON, индивидуальная упаковка.

kizlabelpack
03

Хранение

ff store --zone=A4 --inv=14d

Адресное хранение 1 500 м², инвентаризация раз в 14 дней, отдельные зоны для food и косметики.

1500m²inv 14d
04

Сдача на РЦ

ff ship --rc=koledino,horugvino,tver

Слоты в Коледино, Электросталь, Подольск, Хоругвино, Тверь. Палетирование, документы, фуру подгоняем мы.

fbofbsslots
05

Возвраты и QC

ff return --qc --repack

Перебираем, переупаковываем, фотографируем. Годное обратно в продажу, брак в утиль или вам по запросу.

qcrepack
06

API и webhooks

ff api keys --erp=1c,moysklad

REST + webhooks для остатков, статусов, событий. Интеграция в 1С / МойСклад / Битрикс24 за один день.

restwebhookerp
